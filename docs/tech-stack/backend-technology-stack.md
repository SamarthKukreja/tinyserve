# TinyServe Backend Technology Stack

Canonical implementation target:

- Core runtime: C++17/C++20
- Build system: CMake
- Offline tooling: Python 3
- Test command: defined during Wave 0
- Benchmark outputs: stored under a documented results directory
- Runtime modes: CPU baseline first, optional CUDA/INT8/server later

Architecture boundaries:

- C++ runtime owns tensor storage, weight loading, CPU kernels, decode loop, KV cache, and CLI.
- Python tools own conversion, reference dump generation, and benchmark report processing.
- Documentation must identify fixture-only support, real-model-gated support, and unsupported features separately.

Compatibility expectations:

- CPU-only validation must work without CUDA.
- CUDA work must skip cleanly when no CUDA toolchain or GPU is present.
- Any external model conversion must be reproducible and documented.
- Real-model benchmark numbers must not appear unless generated by checked-in scripts or clearly linked result files.
